# Kiln on Android

1. On the phone, tap **[Download Kiln.apk](https://github.com/nklobe12/kiln-launcher/releases/download/nightly/Kiln.apk)**.
2. Open it. If Android asks, allow your browser or Files app to install unknown apps.
3. Open Kiln. Sign in with the Microsoft account that owns Minecraft: Java Edition, using the account selector at the top.
4. Tap **Browse**, install a modpack or make a profile, then tap **Play**.

Notes
- Android 8 or newer with a 64-bit (arm64) phone works best. Give Java about half your RAM (profile → Settings → Memory).
- You can change the renderer and touch controls in **Settings → Launcher settings**.
- Forge and NeoForge run their installer the first time you tap Play. Wait for it to finish, then tap Play again.
- Kiln isn't from the Play Store, so Android or Play Protect may warn you before installing. Tap **Install anyway**.
